2. Categories of Personal Data Collected

We adhere strictly to the principle of data minimization (GDPR Article 5(1)(c)). We collect only the data strictly necessary to calculate wedding budgets and cashflow trajectories:

Category Specific Data Elements Source
Wedding Planning Data Couple names, estimated wedding date, target budget, bank savings balance, paycheck cadence, planned savings rate. Direct user input
Expense & Milestone Records Vendor names, item notes, estimated/actual costs, payment installment amounts, due dates, paid statuses. Direct user input
Technical & Device Telemetry IP address (anonymized), browser user agent, device screen dimensions, error stack traces. Automated via HTTP headers
Consent Records Consent version, timestamp, granular category flags, Global Privacy Control (GPC) state. Browser localStorage

3. Legal Bases for Processing (GDPR Article 6)

  • Performance of a Contract (Art. 6(1)(b)): Processing couple financial entries and milestone schedules to compute savings recommendations and timeline warnings.
  • Legitimate Interests (Art. 6(1)(f)): Maintaining server network security, detecting malicious abuse, and enforcing Content Security Policies.
  • Explicit Consent (Art. 6(1)(a)): Executing non-essential performance telemetry and activating optional Google Gemini AI Copilot financial audits.
  • Legal Obligation (Art. 6(1)(c)): Retaining records of data subject erasure requests and regulatory compliance audits.

4. Authorized Third-Party Sub-Processors

We partner only with security-certified service providers bound by Data Processing Agreements (DPAs) incorporating standard contractual clauses (SCCs):

  • Vercel Inc. (USA): Edge hosting, serverless routing, reverse proxy CDN.
  • Supabase Inc. (USA/EU): Cloud database infrastructure, Row-Level Security (RLS) PostgreSQL storage.
  • Google Cloud Vertex / Gemini API (USA): Stateless AI Copilot inference (prompts and context are NOT retained for model training).
  • jsDelivr / Cloudflare (Global): Static asset CDN for client libraries.

5. Universal Data Subject Rights (GDPR & CCPA/CPRA)

Regardless of geographic residency, all EternalPlan users possess the following enforceable privacy rights:

  • Right of Access & Portability: Obtain a complete, structured JSON export of all your stored budget and milestone data.
  • Right to Erasure ("Right to be Forgotten"): Permanently delete all local and cloud-stored records.
  • Right to Rectification: Edit or correct any inaccurate expense or milestone values directly within the UI.
  • Right to Restrict or Object: Restrict optional telemetry processing at any time.
  • Right to Non-Discrimination: We will never deny services, alter calculation speeds, or degrade functionality for exercising privacy rights.

To submit an automated data export or permanent deletion request, visit our Data Subject Access Request Portal (DSAR).

6. Global Privacy Control (GPC) & Do Not Track

We fully recognize and honor the Global Privacy Control (GPC) signal broadcast by supported web browsers pursuant to CCPA regulations (§ 999.315). When a GPC signal is detected, all marketing and non-essential analytical tracking are immediately suppressed with no user action required.

7. Supervisory Authority Complaints

If you are located in the European Economic Area (EEA) or UK and believe our processing infringes upon your statutory rights, you have the right to lodge a complaint with your local Data Protection Authority (DPA) under GDPR Article 77.
